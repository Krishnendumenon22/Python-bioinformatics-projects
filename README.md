# Python Bioinformatics Projects

Small Python scripts for basic sequence-analysis tasks, written while learning bioinformatics.

## Projects
- **Project 9: SNP detection** - compares a patient sequence to a reference sequence and reports every position where the base differs.
-  **Data analysis notes** (`python_data_analysis_notes.ipynb`) - pandas, seaborn, glob, and NumPy examples on sample data (grouped bar plots, box plots, batch file handling, sequence comparison).
-  **DNA complement and EcoRI sites** (`dna_complement_and_ecori_sites.ipynb`) - builds complement and reverse-complement strands, finds EcoRI restriction sites, and calculates digest fragment sizes.

## How to run
Open the notebook in Jupyter or Google Colab and run the cells in order.
