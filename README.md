# Python Bioinformatics Projects

Small Python scripts for basic sequence-analysis tasks, written while learning bioinformatics.

## Projects
- **Project 9: SNP detection** - compares a patient sequence to a reference sequence and reports every position where the base differs.

## How to run
Open the notebook in Jupyter or Google Colab and run the cells in order.
